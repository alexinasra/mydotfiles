# Agent Notes

## Project

This repo is a Sass-based full desktop theme. It builds one light/default theme variant across GTK 2, GTK 3, GTK 4, GNOME Shell, Cinnamon, Metacity, Plank, Unity, and XFWM. Do not add dark variants unless explicitly requested.

## Important Files

- `src/_color_theme.scss` is generated by `scripts/generate-color-theme.sh`.
- `src/_theme.scss` maps generated palette values into semantic theme variables.
- `src/gtk-3.0/sass/_common.scss` contains GTK 3 selectors.
- `src/gtk-4.0/sass/_common.scss` contains GTK 4 selectors.
- `src/gnome-shell` and `src/cinnamon` contain shell Sass and assets.
- `src/gtk-2.0`, `src/metacity-1`, `src/plank`, `src/unity`, and `src/xfwm4` contain desktop integration assets.
- `meson.build` and `src/**/meson.build` control compilation and install paths.

## Commands

Generate colors:

```sh
scripts/generate-color-theme.sh
```

Build:

```sh
meson setup -Ddatadir=".themes" --prefix="$HOME" mybuild --wipe
meson compile -C mybuild
```

Install dry run:

```sh
meson install -C mybuild --destdir /tmp/gtktheme-install
```

Local install:

```sh
meson setup -Ddatadir=".themes" --prefix="$HOME" mybuild --wipe
meson install -C mybuild
```

## Conventions

- `theme_dir` intentionally uses `join_paths(get_option('datadir'), theme_name)`. With `-Ddatadir=".themes" --prefix="$HOME"`, this installs to `$HOME/.themes/<theme_name>`.
- Keep generated CSS out of source control; Meson writes it under build directories.
- Keep `src/_color_theme.scss` compatible with pywal-style `$colorN: #rrggbb;` Sass variables.
- Prefer semantic variables from `src/_theme.scss` in GTK Sass files instead of using raw `$colorN` values directly.
- Avoid fractional RGB values in generated CSS; use helpers in `src/_theme.scss` when mixing colors.
