# Custom Desktop Theme

A Sass-based full desktop theme. It includes GTK 2, GTK 3, GTK 4, GNOME Shell, Cinnamon, Metacity, Plank, Unity, and XFWM theme assets.

## Layout

- `src/_color_theme.scss` is generated by `scripts/generate-color-theme.sh`.
- `src/_theme.scss` maps generated colors into semantic theme variables.
- `src/gtk-3.0/gtk.scss` and `src/gtk-4.0/gtk.scss` compile to GTK CSS.
- `src/gnome-shell` and `src/cinnamon` compile shell CSS.
- Other desktop integration assets live under their matching `src/*` directories.

## Build

```sh
npm install
meson setup -Ddatadir=".themes" --prefix="$HOME" mybuild --wipe
meson compile -C mybuild
```

## Install Locally

```sh
meson setup -Ddatadir=".themes" --prefix="$HOME" mybuild --wipe
meson install -C mybuild
```

This installs to:

```text
$HOME/.themes/CustomGTK
```

The installed theme name defaults to `CustomGTK`. Override it with:

```sh
meson setup -Dtheme_name=MyTheme -Ddatadir=".themes" --prefix="$HOME" mybuild --wipe
```

## Generate Colors

Use defaults:

```sh
scripts/generate-color-theme.sh
```

Use a pywal-style Sass file:

```sh
scripts/generate-color-theme.sh ~/.cache/wal/colors.scss
```
